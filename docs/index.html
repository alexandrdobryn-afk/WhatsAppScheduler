WA Schedule

Scheduled WhatsApp messages for Android. Create a local rule, choose a start date and exact time, and send prepared messages to WhatsApp groups from your own phone.

Features

Schedule WhatsApp group messages by weekday, start date, and multiple exact times.
Runs locally on Android with Room, AlarmManager, WorkManager, Hilt, and Jetpack Compose.
Uses AccessibilityService only for interacting with the official WhatsApp UI.

Install

  • Download the signed release APK from GitHub Releases.
  • Allow installation from the browser or file manager you use to open the APK.
  • Open WA Schedule and enable the Accessibility service manually in Android Settings.
  • Use the same signed APK line for updates, so Android preserves app data.

FAQ

Does this use WhatsApp Business API?
No. It uses the official WhatsApp app already installed on the phone.

Can it run without Accessibility?
No. Android does not provide a public API for sending personal WhatsApp messages.

Is Google Play distribution planned?
No. This is intended for private APK distribution because automated Accessibility use can conflict with store policy.
