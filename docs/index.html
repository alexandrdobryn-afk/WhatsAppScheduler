WA Schedule

A local Android app for scheduling user-configured WhatsApp actions at selected times.

WA Schedule stores rules on the device, opens the official consumer WhatsApp app for configured actions, and does not operate a developer backend, analytics SDK, or advertising SDK.

Privacy Policy GitHub repository Latest release

Features

Create deterministic schedules with target chat or group, message text, dates, weekdays, times, and enabled state.
Uses Android scheduling APIs and Accessibility Service for the exact WhatsApp action configured by the user.
Keeps schedule data, preferences, and execution history locally on the Android device.

Google Play preparation

Google Play distribution is being prepared. The current documentation package includes the Privacy Policy, Accessibility disclosure materials, Data Safety draft, and manual runtime validation checklist required before publication.

Privacy

WA Schedule does not collect schedule, message, diagnostic, or Accessibility-derived data for the developer. User-authored messages are transferred to WhatsApp only as part of the user-requested send action.
